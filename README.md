# 一级建造师 · 机电工程管理与实务 · 学习复习系统

> 基于 WorkBuddy 项目框架的**开箱即用**机电专业单科学习复习系统。
> 纯前端单页应用，**无需服务器、无需安装依赖**，双击 `index.html` 即可在浏览器运行。

---

## 🚀 快速开始

1. 直接用浏览器打开本目录下的 **`index.html`**（推荐 Chrome / Edge / Firefox）。
2. 无需联网、无需 `npm install`、无需启动服务——所有数据已随包内置。
3. 学习记录、错题、收藏、进度、模考成绩均保存在浏览器 **localStorage**，关闭页面不丢失；换设备需重新练习。

> 若浏览器对 `file://` 下的本地脚本有限制（极少情况），可在本目录执行 `python -m http.server` 后访问 `http://localhost:8000`。

## 🧩 数据格式（如需扩充题库）

每题对象（存放于 `YJ_DATA.mechanical.questions` 数组）：

```js
// 单选题
{ id:"M01", chapter:"1H411010", type:"single", stem:"题干",
  options:["A. …","B. …","C. …","D. …"], answer:["B"],
  analysis:"解析", difficulty:2, freq:"high" }

// 多选题（5 选项，answer 为正确字母数组）
{ id:"M05", chapter:"1H411010", type:"multiple", stem:"题干",
  options:["A. …","B. …","C. …","D. …","E. …"], answer:["A","B","C","D"],
  analysis:"解析", difficulty:3, freq:"high" }

// 实务案例题
{ id:"MC01", chapter:"1H413030", type:"case", difficulty:4, freq:"high",
  stem:"【背景】…",
  subQuestions:[ { q:"第1问…", a:"标准采分点", score:6 } ] }
```

> 章节编号沿用教材代码（如 `1H411010` 机电工程常用材料、`1H413030` 工业管道、`1H420040` 质量管理）。应用启动时会对字段做兼容归一化，直接往 `questions` 数组追加即可，无需改动 `app.js`。

## ⚙️ 说明

- **评分规则（官方对齐）**：单选选对 1 分；多选全对 2 分、少选每对 0.5 分、错选 0 分；案例题按采分点由用户自评分（满分 / 半分 / 0 分）。
- **合格线**：机电实务卷面满分 160 分，合格线 96 分（满分的 60%）。
- **内置题库**：机电实务共 **68 题**（单选 50 + 多选 10 + 案例 8），覆盖 3 篇 16 章中 28 个章节，均含标准答案与解析，例题取自 2024 真题示例、模拟卷 #1 及高频 / 数字考点。可按 `data_mechanical.js` 格式持续扩充至贴近真题规模。
- 所有图表为手写 SVG，无任何外部 CDN 依赖，彻底离线可用。
- 顶部「重置数据」可清空本地全部学习记录（不可恢复）。
